# 🤖 Computer Vision Projects Collection

This repository contains three individual yet insightful Computer Vision applications built with Python. Each project leverages a different aspect of visual recognition using state-of-the-art AI frameworks such as TensorFlow, PyTorch, and OpenCV.

---

## 📌 Projects Overview

| Project Type           | Description                                                                 | Technologies Used                     |
|------------------------|-----------------------------------------------------------------------------|----------------------------------------|
| [🐱🐶 Image Classification](./ImageClassification/README.md) | Binary classification of cats vs dogs using CNN and ResNet50             | TensorFlow, Keras                      |
| [😷 Object Detection](./ObjectDetectionTwoClasses/README.md)          | YOLOv8-based detection of face mask usage (correct/incorrect/none)       | PyTorch, Ultralytics YOLOv8, OpenCV    |
| [🧠 Image Segmentation](./ImageSegmantation/README.md)      | Brain tumor segmentation on MRI scans using a U-Net architecture         | TensorFlow, OpenCV                     |

## 🛠️ Installation & Setup

Make sure you have Python 3.8+ and `pip` installed. Then navigate to the project you want to run and follow its specific `README.md` instructions. Below are some common libraries across all projects:

```bash
pip install tensorflow opencv-python matplotlib scikit-learn pandas ultralytics
```
